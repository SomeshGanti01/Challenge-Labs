# Salted Hashes

## Project Description
This repository contains the Python scripts developed and used for the Salted Hashes practical investigation.

## Objective
The objective was to investigate salted password hashes and recover as many passwords as possible using different password-recovery techniques.

## Tools Used
- Python 3
- Visual Studio Code
- Python hashlib library
- Password wordlist

## Python Scripts
The repository contains scripts used for:
- Inspecting PDF information and metadata.
- Testing possible salt values.
- Testing common password candidates.
- Performing dictionary and wordlist attacks.
- Testing numeric password combinations.
- Comparing calculated SHA-1 hashes with the stored hashes.

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code or Command Prompt.
3. Run the required Python script using:

```bash
python filename.py
```

Replace `filename.py` with the name of the script you want to execute.
